EXECUTION · 防止计划失真

每天只守六条规则

计划不是用来制造“全都完成”的假象，而是持续暴露真实问题。状态、错因和下一步动作，比漂亮的完成率更重要。

RULE 01

先独立，再对答案

大题至少独立思考 15–20 分钟，写出入口和已知条件后再看解析。

RULE 02

答案关掉，再写一遍

算法题、证明题、综合计算题看懂不算会，必须脱离答案复现。

RULE 03

错题只记有效信息

记错因、关键转折和再次测试日期，不抄整页解析制造虚假努力。

RULE 04

未完成也要归档

标记“未完成”，说明是时间不足、难度过高还是状态问题，并决定补做或舍弃。

RULE 05

英语不断线

最忙时也保留单词 30–40 分钟；后续逐步加入阅读、翻译、新题型、完形和作文。

RULE 06

每周用测试校准

周日限时测试后再调整下一周；用真实正确率决定补弱优先级。

完成不是把方框全部变绿，而是让每一次失分都有去处。
